1. Online Banking System → SQL
Needs ACID properties (Atomicity, Consistency, Isolation, Durability)
Transactions must be 100% reliable
Example: PostgreSQL

2. Social Media Platform → NoSQL
Handles huge, unstructured data
Needs horizontal scalability
Example: MongoDB

3. Real-time Chat Application → NoSQL
Requires low latency + fast writes
Eventual consistency is acceptable
Example: Firebase Realtime Database

4. Hospital Patient Records → SQL
Requires data accuracy + relationships
Structured schema (patients, doctors)
Example: Oracle Database

5. IoT Sensor Data → NoSQL
Massive time-series data
High ingestion rate
Example: InfluxDB
